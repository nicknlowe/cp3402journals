## Content Insights
For this forth week, I was able to understand how child themes are employed by developers to customise an existing WordPress theme without directly modifying the main theme files. This approach enables greater flexibility in the design whilst ensuring that the integrity of the original theme is protected.

A child theme works by inheriting the core functionality and styling of the parent theme, while storing custom changes in a separate file structure. This means that any edits made, such as styling adjustments or template modifications, are preserved independently from the original theme. This results in updates to the parent theme not overwriting or removing these customisations in the child theme.

If changes were made directly to the original theme, any future updates released by the theme developer could override these modifications, potentially causing loss of work or inconsistent designs across the website. However, by using a child theme, updates can still be installed safely, as the customised elements remain stored separately. This ensures that the website remains up to date while maintaining all user-created changes, thus making child themes an essential practice for WordPress development.
