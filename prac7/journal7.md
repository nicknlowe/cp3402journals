## Content Insights

For the seventh week, I learnt and explored the fundamentals of PHP including how to manipulate databases using the language. This transition into server-side scripting is a significant step, as it allows for the transformation of static web pages into dyanmic, interactive web applications that respond to user inputs.

Utilising ``<?php ?>`` script delimiters, functions like ``echo`` demonstrates how PHP seamlessly integrates with existing front-end code to generate HTML content on the fly, allowing a website to become fully dynamic and responsive to user inputs and actions. This is typically seen through features like utilising ``echo`` to display a logged-in user's name or personalising a header. Other functions like conditional statements also allow for the control of content, ensuring that the page content responds as intended based on the provided conditions such as the level of access a user has and iterative functions like loops allow for the efficient handling to multiple data entries like large arrays. Additionally, by establishing a connection to a SQLite database, I explored how to execute SQL queries to perform operations such as creating and reading data. This allows the application to store and retrieve persistent data such as information pertaining to a user, ensuring that the information displayed is current and relevant to the active user.
