## Content Insights

For the seventh week, I learnt the basics of PHP including how to manipulate databases using the language. This transition into server-side scripting is a significant step, as it allows for the transformation of static web pages into dyanmic, interactive web applications that respond to user inputs.

Utilising ``<?php ?>`` script delimiters, functions like echo to output HTML demonstrates how PHP seamlessly integrates with existing front-end code to generate content on the fly. Other functions like conditional statements also allow for the control of content, ensuring that the page content responds as intended based on the provided conditions. Additionally, by establishing a connection to a SQLite database, I explored how to execute SQL queries to perform operations such as creating and reading data. This allows the application to store and retrieve persistent data such as information pertaining to a user, ensuring that the information displayed is current and relevant to the active user.

From this, I have learnt that server-side logic languages like PHP are essential for building dynamic, data-driven websites that react to the active user and how content is delivered to enhance their experience.

## Career/Employability/Learning Insights

For this seventh week, I applied my knowledge of PHP as well as SQL queries to develop a functional login and signup page along with user session management. By utilising POST methods to obtain user inputted credentials and executing SQL queries to verify them against a database, I have gained a practical understanding of how to authenticate users as well as control content through session variables. It has been through this practical task that I have gained a significant insight into the relationship between client-side input and server-side validation and how PHP transforms a HTML form into a responsive user experience. Developing a login system also highlighted the importance of utilising security measures such as password hashing and prepared SQL statements to protect sensitive user data from potential vulnerabilities like SQL injection. This exercise has therefore allowed myself to develop a deeper foundational concept for building any web application that requires a secure authetication method and database connection.
