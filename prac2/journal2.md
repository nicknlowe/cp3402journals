## Content Insights
For this second week, I was able to distinguish the difference between static and dynamic websites and how CMS plays a crucial role in transforming a website to respond to user input and data without human intervention. This distinction is fundamental to understanding modern web architecture, as it marks the shift from simply displaying information to creating fully-interactive web environments that can adapt to an individual's session and requests.

A static website delivers fixed content to users and typically requires manual updates to modify information. In this setup, every page exists as an independent HTML file, meaning even a minor update like adding a new blog post requires the manual editing of the individual code. Furthermore, because this content is fixed, these sites lack the server-side logic necessary to personalise the user experience or deliver content tailored to a specific user. In contrast, a dynamic website uses a CMS and database integration to generate content in real time, allowing pages to automatically update based on user interaction and collected data. Platforms like Joomla and WordPress are some of the biggest content management systems providers by marketshare due to the way they make this approach simple by providing templates, plugins and a main dashboard to let users manage their site content in a convenient manner.

If only a static approach was used, updating larger websites would be time-consuming and inefficient, particularly for organisations that frequently change their web content. However, whilst a CMS-based approach may make websites more adaptable and better suited for the organisation, it does increase the website's complexity and requires server know-how and software correctly configured in order to work as intended. This includes managing backend components like databases and server-side scripts.

## Career/Employability/Learning Insights
Upon researching the statistics to determine the true influence of content management systems across hosted websites on the internet, I discovered that close to 70% of the world's websites use a CMS with WordPress alone powering around 43.6% of those sites.

These figures suggest that from an employability perspective, knowledge and proficiency in CMS platforms is not classed as a niche skill but is an expected requirement for graduating IT students looking to enter the world of modern web development. By learning and honing on the skills required to manage a CMS such as understanding database management, my value as a developer could be significantly enhanced as it ensures that I can proficiently demonstrate an ability to create and maintain the CMS-related infrastructure required by the many businesses who rely on such websites to reach their target audiences.
